# 弈境 AI 创作工作站

**简体中文 | [English](README.en.md)**

**本地优先的 AI 漫剧 / 短剧创作桌面工具**

把一部小说变成一部可以交付的漫剧 / 短剧：从故事结构到分镜、从画面生成到成片导出，全流程在一个桌面应用内完成。项目数据存储在本地，模型服务由你自己接入（BYOK）。

---

## 功能特性

- **全链路创作流**：小说导入 → 故事结构 → 分集剧本 → 智能分镜 → 视觉资产（角色 / 场景 / 关键帧）→ 视频生成 → 音频制作（配音 / BGM / 音效）→ 审片质检 → 成片合成导出
- **本地优先**：项目与素材存本地，支持 [ComfyUI](https://github.com/comfyanonymous/ComfyUI) 本地出图；也兼容任意 OpenAI 协议模型服务
- **批量任务队列**：整集生成、逐镜重试、暂停 / 继续、失败自动重试，进度与产物可追溯
- **一致性保障**：角色参考图（IPAdapter）、风格锚点、跨集质检报告
- **授权机制**：免费版 / 商业授权双档，本地离线可用

## 系统要求

| 项     | 要求                                                    |
| ------ | ------------------------------------------------------- |
| 操作系统 | Windows 10 / 11（64 位）                              |
| 内存   | 8 GB 起，推荐 16 GB                                     |
| 显示   | 分辨率 1920×1080 起，推荐 4K；系统缩放 100–150%         |
